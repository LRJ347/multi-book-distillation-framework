# 03 — 阶段 2:候选聚类(DISCOVER)

## 目标

同一概念被多本书提到时合并成一条候选;被错误聚合的不同概念拆开。

## 步骤

1. **相似度匹配**: 对所有 candidates 条目做语义相似度计算
2. **合并**: 同一概念的不同表述 → 合并成一条(保留全部来源标注)
3. **拆分**: 被错误聚合的不同概念 → 拆开

## 产出

`clusters/<cluster-id>.md`:

```markdown
## Cluster <id>: <概念名>

### 包含的候选
- candidates/frameworks.md #3
- candidates/principles.md #7
- candidates/cases.md #12

### 独立证据链
- 链 1: <书 A>(L4, 章节)
- 链 2: <书 C>(L3, 章节)

### 多书交叉度
<M/N 本书> | 独立链数: <K>

### 核心
<一句话>
```

## 门控

| ID | 症状 | 处理 |
|---|---|---|
| DM-1 | 候选聚类过度细分(同一概念被分成多个 cluster) | 合并 |
| DM-2 | 候选聚类过度聚合(不同概念混在一起) | 拆分 |
| DM-3 | 漏掉核心议题(只看了 1 本书目录) | 补扫 |
