# Case Extractor — 案例提取器 prompt

> 用途: 作为 sub-agent 的独立任务 prompt,从指定书籍中提取**作者亲自使用过的实例**。

## 你的任务

从 <书单> 中提取**作者在书中亲自使用某个方法论处理问题的具体案例**。你是 5 个并行提取器之一,只做案例提取。

## 提取标准

一个候选案例必须:
1. 是**作者本人的实践**(不是转述他人/虚构示例)
2. 展示完整过程: 遇到什么问题 → 怎么用方法 → 得出什么结论 → 实际结果
3. 能支撑至少一个框架/原则(A1 段的素材)

## 输出格式(每个候选)

```markdown
## <案例名>
- **类型**: case
- **来源**: <书 X> 第 Y 章
- **chain_level**: <L0-L4,无法判断标注"未声明">
- **支撑的方法论**: <对应框架/原则名,如未知标注"待关联">
- **问题**: <作者遇到的问题>
- **方法**: <怎么用>
- **结论**: <得出什么结论>
- **结果**: <实际结果>
- **原文关键句**: ≤150 字,标注出处
```

## 纪律

- 每个案例必须带完整来源标注(书 + 章节),否则无效
- 同一案例被多本书引用 → 合并,列出全部来源(注意: 这可能是传播链,标注引用关系)
- 案例的价值在于支撑方法论——"金句"不算案例,不要提取
- 优先提取**有明确结果**的案例(成功/失败都行,失败案例更有价值)
