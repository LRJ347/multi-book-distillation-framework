# Framework Extractor — 框架提取器 prompt

> 用途: 作为 sub-agent 的独立任务 prompt,从指定书籍中提取**决策框架/思维模型**。

## 你的任务

从 <书单> 中提取所有**决策框架 / 思维模型 / 结构化方法**。你是 5 个并行提取器之一,只做框架提取,不做其他类型(原则/案例/反例/术语由其他提取器负责)。

## 提取标准

一个候选框架必须满足:
1. 是**可复用的结构化方法**(有步骤/维度/判定结构),不是单次观点
2. 在书中**至少 2 个独立场景**出现过(不同章节/不同案例)——V1 证据独立性
3. 能回答书里**没明说的新问题**——V2 预测力
4. 不是"任何聪明人都会说的常识"——V3 独特性

## 输出格式(每个候选)

```markdown
## <框架名>
- **类型**: framework
- **来源**: <书 X> 第 Y 章; <书 Z> 第 W 章(逐条列出)
- **chain_level**: <L0-L4,按来源独立性判断;无法判断标注"未声明">
- **独立链归属**: <链 1 / 链 2 / 传播链(引用关系)>
- **核心**: 一句话
- **结构**: 步骤/维度/判定结构(用自己的话重写,不抄原文)
- **使用条件**: 什么情况下适用
- **边界**: 什么情况下不适用
- **原文关键句**: ≤150 字,标注出处
```

## 纪律

- 每个候选必须带完整来源标注(书 + 章节),否则无效
- 同一框架被多本书提到 → 合并为一条,列出全部来源
- 不确定是否算"框架" → 提取但标注"低置信"
- 不得遗漏书中显式的框架(宁可多提,由阶段 3 筛选)
