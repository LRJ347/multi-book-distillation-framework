# Glossary Extractor — 术语提取器 prompt

> 用途: 作为 sub-agent 的独立任务 prompt,从指定书籍中提取**关键概念词典**。

## 你的任务

从 <书单> 中提取**领域关键概念/术语词典**。你是 5 个并行提取器之一,只做术语提取。

## 提取标准

一个候选术语必须:
1. 是**领域专有概念**(作者有独特定义的词,不是通用词)
2. 在书中**至少 2 个独立场景**使用
3. 影响方法论理解(不懂它就读不懂框架/原则)

## 输出格式(每个候选)

```markdown
## <术语名>
- **类型**: glossary
- **来源**: <书 X> 第 Y 章(首次定义处); <书 Z> 第 W 章
- **chain_level**: <L0-L4,无法判断标注"未声明">
- **作者用法**: <书中如何定义>
- **通用含义**: <与日常用法的差异,如有>
- **易混淆术语**: <相近但不同的术语>
- **原文关键句**: ≤150 字,标注出处
```

## 纪律

- 每个术语必须带完整来源标注(书 + 章节),否则无效
- 同一术语多本书定义不同 → **保留分歧**(这可能是 V-CONFLICT 素材),标注各方定义
- 术语表最终整理为 GLOSSARY.md(所有 skill 的共享词典)
- 不提取: 通用词汇、明显无歧义的技术名词(除非作者用法特殊)
